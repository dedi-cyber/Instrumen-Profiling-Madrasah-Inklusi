Setup Backend Google Apps Script (`Code.gs`)

Catatan Pemasangan: Tempelkan kode dibawah ini ke menu Ekstensi > Apps Script pada Google Sheet Database Anda.
File: Code.gs

Langkah Deployment Web App:

  1. Buka Google Sheets Target Database.
  2. Klik Ekstensi > Apps Script.
  3. Ganti seluruh isi file Code.gs dengan kode di atas.
  4. Klik Terapkan (Deploy) > Formasi baru (New deployment).
  5. Pilih Aplikasi Web (Web App), Jalankan sebagai: Saya (Me), Akses: Siapa saja (Anyone).
  6. Klik Terapkan dan berikan otorisasi izin akses.
